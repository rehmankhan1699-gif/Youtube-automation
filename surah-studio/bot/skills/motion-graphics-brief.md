# Motion graphics brief

Write a scene list synced to the Urdu voiceover for Islamic motion graphics.

## Visual language

- Calm palette: deep greens, soft golds, night-sky blues. No neon purple UI look.
- Full-bleed atmospheric backgrounds (geometry, calligraphy silhouettes, soft particles).
- Typography: large Surah title cards; avoid cluttered lower-thirds stacks.
- No fake "card dashboard" layouts for the hero moments.

## Scene format

For each scene include:

- `t` start–end (seconds)
- `visual` — what is on screen
- `text` — on-screen Urdu/Arabic title if any
- `motion` — fade, ken burns, particle drift, type-on

Aim for **12–20 scenes** across 7–8 minutes. Mark 3–5 moments that become Shorts/Reels hooks.
